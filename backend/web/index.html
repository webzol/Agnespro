在这里集中管理 Agnes AI API Key、API 路由、默认 AI 模型。所有改动立即生效(route 切换除外,需要重启服务)。

1. API Key

密钥经 AES-256-GCM 加密后存到 data/.apikey,不会以明文出现在任何日志或代码中。

2. API 路由

选择 Agnes AI 网关地址。切换后需要重启服务才能生效。

3. 默认 AI 模型

这些是后台的默认值。新建任务时用户可以临时覆盖这里的设置。

4. 可用模型列表

从当前 API Key 拉取的 Agnes 网关可用模型(只读,按类型分组)。
